/api/cron/whop-reconcile

Whop payout drift sweep. The safety net behind the identity_profile.* webhook, which Whop drops permanently after 3 retries (~70s). Reads GET /identity_profiles/{idpf_…} — the only endpoint exposing status, payout_status and payouts_enabled together — and keys completion on status: approved. ONE-WAY: it may OPEN the payout gate, never close it, because a parent-company API key is known to under-report (linked_companies reads empty here but arrives populated on the webhook). Revocation stays with identity_profile.rejected/needs_action. Reports connected accounts that have NO stored Whop ids — the signature of a webhook that never resolved. Bearer CRON_SECRET when set. Hourly (vercel.json); it is also the retry backstop for referral and recruiter share transfers, which do nothing while WHOP_TRANSFERS_ENABLED is not exactly true (off in production per a read-only check on 2026-10-14/15).
